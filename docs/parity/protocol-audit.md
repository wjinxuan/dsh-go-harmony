## 复用和传输边界

- 若采用 Flutter 鸿蒙 HAP，可直接保留 `packages/dsh_client`、`packages/dsh_remote` 的 Dart 协议和绝大部分单元测试。前者使用 `dart:io` 及 Dart 依赖，后者依赖 `cryptography`、`crypto`。`app` 里的原生插件、WebRTC 和 Android MethodChannel 仍需适配；在鸿蒙 Dart VM 验证 `Host` 覆盖、无 Origin、Socket、证书和二进制流。 [dsh_client 依赖](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/packages/dsh_client/pubspec.yaml) · [dsh_remote 依赖](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/packages/dsh_remote/pubspec.yaml) · [应用依赖](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/pubspec.yaml#L39)
- 若继续 ArkTS，抽出 `DshCarrier.call(endpoint,args,timeout) -> RpcResult`、`openLink() -> MuxLink`、`close()` 和 `capabilities`。`MuxLink` 提供 `start(onFrame,onLost)`、`open`、`cancel`、`sendItem`、`endUplink`、`close`。额外能力用可选的 HTTP 二进制/桥接访问与 `WorkspaceUploadCarrier`。保留现有 `createRpcRequest`、`createMuxOpen`、网络调用、基本字段和会话所有权校验。调整 `parseRpcResponse`，成功及失败均验证 `rpcId`，区分合法 Host 拒绝、传输失败和协议错误，UI 只读取可展示错误。 [上游 DshCarrier](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/packages/dsh_client/lib/src/carrier.dart#L34) · [现有 DshWire.ets](../../entry/src/main/ets/dsh/DshWire.ets#L61)
- mux 对每条连接分配 generation，在 `$events ready` 后开放流，按 `streamId` 分发任意数量的流，断线重开只读流并校验旧帧、补历史和活动尝试。`$events/result` 使用当前 `clientId`，pending 以 `eventId` 去重并处理取消；一般变更请求断线后由用户核实结果。使用上游断线、历史补洞、跨 generation 审批和终端测试作为对照。 [DshMux](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/packages/dsh_client/lib/src/mux.dart#L106) · [事件结果](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/packages/dsh_client/lib/src/session_api.dart#L717) · [测试与捕获帧](https://github.com/ccch1mneyyy/dsh-Go/tree/v1.0.15/packages/dsh_client/test)
- 本机、SSH 与普通 HTTPS 共享 HTTP 载体。认证需持有 `dialOrigin` 与服务端所见 `Host` authority，支持 Cookie 登入和过期恢复。上游 Dart 不发 Origin。鸿蒙 Network Kit 可附带 Origin，API 26 增加 `supportOriginPort`，默认关闭并按连接 URL 的端口填充。现有本机修正规则只适用于本机引擎，SSH 需实测能够独立控制 authority 和 Origin，必要时由原生 HTTP/WS 或回环代理提供这个能力。不得在任意远端去除 Cookie 或 Origin/Host 验证。 [上游 DshConnection](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/packages/dsh_client/lib/src/connection.dart#L142) · [鸿蒙 WebSocket](https://developer.huawei.com/consumer/en/doc/harmonyos-references/js-apis-websocket/) · [本机兼容规则](../../runtime/main.cjs#L65)

## SSH

- 原版 `dartssh2 ^4.1.0`，支持密码、OpenSSH 私钥和口令。SHA-256 主机指纹首次由用户确认并持久化，变化时拒绝。通过 SSH exec 运行 POSIX shell 引导，先探测并复用同一命令、进程和有效启动 URL，再用 `nohup dsh web --host 127.0.0.1 --port 0 --no-open` 或用户指定命令启动，保存 `$HOME/.dsh-app-remote/{web.pid,web.cmd,web.log}`。远端须有 SSH、shell、允许转发及可运行的 DSH。 [ssh_transport.dart#L99](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/remote/ssh/ssh_transport.dart#L99) · [引导 #L67](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/remote/ssh/remote_bootstrap.dart#L67) · [启动 #L217](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/remote/ssh/remote_bootstrap.dart#L217)
