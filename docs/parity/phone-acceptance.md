## 已确认的平台差异

- 普通手机 HAP 的系统 Shell/PTY、任意包管理安装脚本受进程/沙箱限制；远端 Shell/PTY 与远端包管理保留真实路径，本机返回真实能力结果。
- Android Shizuku/root/ADB、私有虚拟屏、任意已安装应用枚举，以及应用外悬浮宠物没有普通手机 HAP 可直接使用的同权限接口。系统单次截图、允许的系统意图与伙伴桌面卡片已经接入；无障碍节点/手势虽有实现和 SDK 类型，该 API 26 商用手机上的普通 HAP 启用入口尚未证实。官方 API/设备支持边界见 [手机能力](phone-native.md)，不强行启用，也不宣称所有 HarmonyOS 设备永久不支持。
- 当前公开快捷方式 API 支持声明式入口及可见性控制；新对话/语音静态入口可验收，Android 动态近期会话和任意图片固定快捷方式没有直接等价实现。
- 用量统计只使用真实设备信息；原版统计接口对 SDK/设备值有校验，不支持的设备不伪造 Android 信息。宿主验证采用合成接收端，原版统计服务是否接收本机真实数据仍待验。
- Live2D 官方运行库/角色包按原版导入流程使用有权使用的本机文件；未伪造内置角色或授权。
- 伙伴电量与系统通知信号在固定原版本身声明不可用；执行结果信号仅接受实际生产器，受限的本机 Shell 不伪报命令成功。
