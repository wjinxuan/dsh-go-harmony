# 消息附件、会话导出和分享

基于 dsh-Go v1.0.15 和本机运行时固定的 DSH 0.2.2-rc.1。下列宿主检查使用现有 ZIP、隔离数据目录和回环测试模型，未更改运行时或手机数据。

## 原版消息附件

1. 输入栏的 `＋` 打开相册、拍照和文档选择。按 PNG、JPEG、GIF、WebP 文件头识别内联图片，其余按文件处理。原版限制每条消息 9 个附件，单图片 20 MiB，单普通文件 200 MiB，累计 400 MiB。实际提交还须满足 `imageLimits` 和主机传输限制。选择界面返回后校验会话和连接代次，选中项可逐个从预览栏移除。 [选取与限额](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/state/attachments.dart#L13) · [输入栏操作](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/ui/chat/chat_screen.dart#L945) · [预览栏](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/ui/chat/widgets/attachments.dart#L67)
2. 文件走同源认证 `POST /api/session/uploadFileBinary?sessionId=…&name=…`，请求体为 `application/octet-stream`。成功包为 `{ok:true,value:{receiptId,file:{attachmentId,name,bytes}}}`，应用根据 `ok` 判断结果，HTTP 200 也可携带错误。HTTP 404 才记为当前主机缺少二进制路由，回退 `fileUploads/upload` 参数 `{agentId,request:{data:base64,name?}}`，返回 `{receiptId,file}`，原版内联回退限制 30 MiB。超时或其他传输错误由调用者报告。主机上传收据按接收会话和存活代理隔离，提示进入日志或待发项被撤回时收据会退役。 [上传协议](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/packages/dsh_client/lib/src/session_api.dart#L475) · [原版发送状态](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/state/chat_state.dart#L1395)
3. `session/prompt` 接收 `{request:{requestId,sessionId,mode,content}}`，内容按原版顺序为 `{type:'text',text}`、`{type:'image',mediaType,data:base64,name?}`、`{type:'file',receiptId}`，允许仅附件。只有 `session/attachment-invalid` 的 `details.reason === 'MODEL_DOES_NOT_SUPPORT_IMAGES'` 才把图片按文件重新暂存，以相同 `requestId` 提交并提示用户。文件暂存、回退或提交期间继续校验连接所有权。同一发送尝试保留请求 ID，依靠服务端对待发队列和日志去重。 [提交协议](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/packages/dsh_client/lib/src/session_api.dart#L436) · [图片回退](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/state/chat_state.dart#L1424)
4. `session/follow` 和 `session/page` 的 `user/message.data.content` 持久化 `{type:'file',attachment:{attachmentId,name,bytes}}` 和 `{type:'image',attachment:{attachmentId,mediaType,bytes?,width?,height?,name?},offloaded?}`。保留图片引用的完整已知字段，`session/attachment {request:{sessionId,attachment}}` 返回 `{attachment,data:base64}`。仅旧主机明确返回 `gateway/arguments-invalid` 或 `gateway/input-invalid` 时按连接代次回退到 `{sessionId,attachmentId}`。原版历史普通文件为名称/大小卡，图片是按需下载的缩略图与全屏图库。 [历史 DTO](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/packages/dsh_client/lib/src/models.dart#L18) · [图片读取](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/packages/dsh_client/lib/src/session_api.dart#L549) · [历史附件 UI](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/ui/chat/widgets/attachments.dart#L178)

## 鸿蒙最小实现路径

- 选取使用 `DocumentViewPicker` 和 `PhotoViewPicker`，通过授权 URI 打开文件。保留临时选取记录 `{id,name,byteLength,mediaType?,localPath}`，本地缓存采用独立私有目录。大文件使用 `rcp.UploadFromFile`，只有老主机回退需要整包 base64。模型兼容图片使用有明确堆预算的内联路径。草稿附件在发送失败时留在托盘，切换主机或会话后废弃旧请求结果。 [鸿蒙选取文件](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/select-user-file/)
- 客户端接口可为 `uploadFile(sessionId,path,name): Promise<DshFileReceipt>`、`promptWithAttachments(sessionId,text,drafts,requestId,mode)`、`readSessionImage(sessionId,ref)`。复用已有 JSON-RPC、认证和 `DshMessage.content`，在转录显示层把图片/文件引用转成附件 DTO，并让行版本跟随附件列表变化。附件消息从队列移除后需保留原始选取数据、重新暂存；其他设备已有的文件收据无法从持久引用复用，继续保持不可立即重发。
- 现有 ZIP 在宿主下通过二进制和 JSON 两种真实文档上传、仅附件提示、历史文件引用及 ZIP 内文件字节的路径检查。应用内 DSH 对文件向模型传递的是可读路径提示，文件实际存于 `$DSH_HOME/attachments/v1`，鸿蒙工作区后端只给工作区路径。若允许工具读附件，需要按会话归属校验且仅开放已提交、已校验内容摘要的附件读取。禁止把附件根或应用数据根加入通用工作区许可。 [工作区边界](../../runtime/workspace-fs.mjs#L35)
- 固定依赖 `dsh-attachment-local/lib/index.js` 的 `publishImmutableAlias` 和 `publishStagedObject` 使用 hardlink。设备此前已实测拒绝会话日志 hardlink，现有补丁只处理会话日志和工作区写入。附件持久化需要单独验证其设备结果，再按源哈希和目标路径适配不可覆盖发布及 alias，保留目录同步、摘要验证和失败清理。该依赖的 `detectImage`、`probeImage` 和归一化还要求 Sharp/libvips。在当前 ZIP 的 `--no-addons` 宿主回环测试中，1×1 PNG 的内联及原始图片上传均因 Sharp 无法加载而失败。原生图片工具需独立接入经过验证的解码、像素限制、归一化及持久引用读取，单纯换 picker 或更改扩展名不会恢复。

## 两种导出

- 会话日志走认证 `GET /api/session.export?sessionId=…&includeDescendants=true`，HTTP 200 和 `application/zip`。名称为 `dsh-session-<安全会话ID>.zip`。包里包含 `session.v4.jsonl`、可选 `subagents/<id>/session.v4.jsonl`、`media/<id>.<ext>` 及 `files/<前缀>/<摘要>/<文件名>`。本地/HTTP/SSH 转发可用，DSH Remote 隧道没有该 HTTP 路由。鸿蒙客户端使用 RCP 文件目的地下载到独立缓存，校验类型及 ZIP 签名后给系统分享或保存选择器。原版 UI 同样提供保存和分享两个动作。 [上游日志 API](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/packages/dsh_client/lib/src/session_export.dart#L15) · [原版导出动作](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/state/session_export.dart#L37) · [鸿蒙导出客户端](../../entry/src/main/ets/dsh/DshClient.ets#L227)
- 分享回复或会话预览属于另一条流程。原版从会话记录构建经过脱敏的分享内容，再按目标生成纯文本、Markdown、HTML、`.dshgo`、PNG 卡片或独立的托管链接。首个原生端到端路径可以从当前会话记录构建文本并交给系统分享。精确复刻还需原版脱敏、配对截取、附件选择和独立编码器。 [分享入口](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/ui/share/share_entry.dart#L26) · [文件与托管链接](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/ui/replay/conversation_out.dart#L25) · [PNG 卡片](https://github.com/ccch1mneyyy/dsh-Go/blob/v1.0.15/app/lib/ui/share/share_export.dart#L22)
